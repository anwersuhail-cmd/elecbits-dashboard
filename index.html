☁ Supabase Cloud Sync
Cloud sync is already configured in this dashboard.
One-time setup (free, 2 minutes):
1. Go to jsonbin.io → Sign up free
2. Click New Bin → paste {} → Save → copy the Bin ID
3. Go to API Keys tab → copy your Master Key
4. Paste both below → Save Config
5. Click ↑ Save to Cloud to push data
6. Share this HTML file with your team — they use the same Bin ID + Key
How team sharing works:
• Each person makes edits locally → clicks ↑ Save to Cloud to push
• Others click ↓ Get Updates to pull the latest version
• Supabase stores the shared dashboard data in the cloud
• The publishable key is intended for browser-side use; database access is controlled by Supabase policies
